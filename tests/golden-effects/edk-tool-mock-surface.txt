All mock modules in this fixture are deterministic data constructors. Action
results are not asserted to have fake default bodies, snapshots, diffs, vector
hits, directory entries, email deliveries, GitHub API payloads, document
conversions, PDF parses, citations, or evaluation fixtures; the calls exist to
keep package-owned action boundaries visible for future package-mode effect
replay. The mocks are not default handlers and must not be registered as
runtime substitutes for network, browser, git, vector, database, filesystem,
email, GitHub, document, PDF, or evaluation actions.

Scenario assertions use sequential guards rather than long boolean
conjunctions, so this fixture does not depend on the current frontend accepting
large `&&` assertion chains during HIR lowering/checking.

`edk.db.tools.query.query_readonly` is intentionally unpublished while runtime
mutation rejection is blocked in
`tests/blocked/edk-db-query-readonly-runtime-guard.txt`; this fixture must not
fake that guard with empty query results.
