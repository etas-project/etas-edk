# HTTP Requirement Coverage

This file maps the EDK HTTP objective to current EDK-side evidence. It is not a
completion claim for compiler, interpreter, `etas_std`, or host work. Rows
marked blocked require changes outside `etas-edk`.

| Requirement | Evidence | Status |
| --- | --- | --- |
| Public API exposes only generic `request/get/post/put/patch/delete/head`. | `packages/edk-http/src/edk/http/api.es`; root facade in `packages/edk-http/src/edk/http.es`; deleted opinionated JSON/text/tool wrappers; `std-requirements/http/negative/client_request_entry_forbidden`; `std-requirements/http/negative/opinionated_api_forbidden`; `tests/fixtures/negative/edk_http_opinionated_api_forbidden`. | Covered in EDK source and negative fixtures. Root and `edk.http.api` both reject `post_json`; `edk.http.tools.*` remains absent. |
| Method wrappers parse URL strings, construct normalized `HttpRequest` values, and call the single public `request(req)` execution path. | `packages/edk-http/src/edk/http/api.es`; root facade in `packages/edk-http/src/edk/http.es`; direct `edk.http.api` and root facade request construction checked by `packages/edk-http/src/edk/http/package_api_contract.es` and `std-requirements/http/positive/edk_http_request_contract`. | Covered in source; public summaries use `EdkHttp.request`, while method/host stay in the runtime action payload. |
| `post/put/patch` preserve the caller-provided request body. | `packages/edk-http/src/edk/http/package_api_contract.es`; `std-requirements/http/positive/edk_http_request_contract`. | Covered before transport. |
| Root HTTP calls request the high-level action family `EdkHttp.request`. | `packages/edk-http/src/edk/http/policy.es`; `std-requirements/http/positive/external_root_api_effect_facts`. | Source target is present; method/host are payload fields for runtime policy and trace, not action type arguments. |
| User monitor/check templates can allow or deny HTTP requests. | `tests/blocked/edk-http-policy-templates.txt`. | Blocked: legacy `policy { allow/deny }` fixtures were removed; method/host-specific allow/deny waits on runtime payload monitor/check support. |
| Root/API `get/post/...` calls preserve request payload method/host for policy and trace. | `packages/edk-http/src/edk/http/action_payload.es`; `std-requirements/http/verify.sh`. | Action family coverage is checked. Payload-aware policy templates remain blocked separately in `tests/blocked/edk-http-policy-templates.txt`. |
| Default handler is real source code, not an empty file. | `packages/edk-http/src/edk/http/api.es` defines `EdkHttpApiDefault` over `HttpActionRequest` / `HttpActionResponse`, lowers and raises the runtime payload, and delegates to `edk.http.transport.execute_request`; `packages/edk-http/src/edk/http/handlers/default.es` remains a layout facade marker; `std-requirements/http/verify.sh` asserts the API handler delegates to source transport. | Covered in EDK source and verifier. |
| Empty handlers cannot satisfy HTTP actions. | `std-requirements/http/negative/empty_handler_forbidden`; `tests/fixtures/negative/edk_http_empty_handler_forbidden`; `std-requirements/http/verify.sh`. | Covered as fail-closed runtime behavior: `etas run` with an empty handler exits with `analysis::UnhandledEffectAction` and does not return a fake response. Current `etas check` accepts the empty handler shape, so static `type::EmptyHandler` rejection remains a frontend/handler-checker gap. |
| EDK HTTP dogfoods public std substrate. | `packages/edk-http/src/edk/http/transport.es` imports and calls `std.net.tcp.connect`, `std.tls.connect`, `std.stream.write_all`, `std.stream.flush`, `std.stream.read_until_limit`, `std.stream.close`, `std.http.codec.encode_request`, `std.http.codec.decode_response_head`, and `std.http.codec.decode_response`. | Covered in source. |
| Bottom actions appear in requested/default action summaries and are not swallowed. | `packages/edk-http/src/edk/http/package_api_contract.es`; `packages/edk-http/src/edk/http/transport.es`; `tests/golden-effects/edk-http-request.txt`; `etas effects` reports `Net.tcp_connect`, `Tls.handshake`, `Stream.write`, `Stream.flush`, `Stream.read`, and `Stream.close`; `std-requirements/http/positive/external_root_api_effect_facts`. | Transport source still dogfoods bottom substrate actions. End-to-end summaries must preserve `EdkHttp.request` and default transport actions without putting method/host payload values into `<...>`. |
| Open TCP/TLS streams are not abandoned on source-visible transport errors. | `packages/edk-http/src/edk/http/transport.es`; `tests/golden-effects/edk-http-request.txt`. | Covered in source: write, flush, response-read, and TLS handshake failures attempt best-effort `Stream.close` while preserving the original `HttpError` classification. |
| URL authority keeps explicit ports and rejects invalid direct ports before TCP. | `packages/edk-http/src/edk/http/url/parse.es`; `packages/edk-http/src/edk/http/handlers/preflight.es`; `packages/edk-http/src/edk/http/package_smoke.es`; `tests/fixtures/positive/edk_http_pure_surface`. | Covered in source and executable smoke: root wrappers accept absolute URL strings, parser results no longer leak `Error<IndexError>`, default ports are preserved, custom explicit ports parse, invalid port text/ranges are rejected, and effects output reports `Net.tcp_connect[std.net.tcp.host, std.net.tcp.port]`. |
| `TlsStream` can be used through the `std.stream` byte-stream functions. | `std-requirements/http/positive/std_stream_substrate`. | Covered. |
| Direct network action without a handler must not execute. | `std-requirements/http/negative/unhandled_action_no_handler`; `tests/fixtures/negative/edk_http_unhandled_action_no_handler`. | Covered: expected runtime failure is `analysis::UnhandledEffectAction`. |
| Private high-level host binding is not available. | `std-requirements/http/negative/private_host_binding_forbidden`; `tests/fixtures/negative/edk_http_private_host_client_forbidden`; `std-requirements/http/verify.sh` checks root API, transport, and default handler sources for forbidden mock/private fallback markers. | Covered: `std.http.request` remains unresolved and the production execution path has no mock/private fallback imports. |
| Unmatched mocks do not return fake HTTP responses. | `packages/edk-http/src/edk/http/mocks/routes.es`; `packages/edk-http/src/edk/http/package_smoke.es`; `tests/fixtures/positive/edk_http_pure_surface`; `std-requirements/http/verify.sh`. | Covered: pure mock route matching returns `matched = false`, `response_status = -1`, and `MockMatchError`; verifier rejects status-zero fake response regressions. |
| Invalid URL maps to `HttpError`. | `packages/edk-http/src/edk/http/api.es`; `packages/edk-http/src/edk/http/package_smoke.es`; `std-requirements/http/positive/edk_http_error_mapping_contract`. | Covered at root string-wrapper, constructor, and preflight level. |
| Preflight rejection contract is source-visible and runtime-executable before transport. | `std-requirements/http/positive/edk_http_error_mapping_contract`; `tests/fixtures/positive/edk_http_pure_surface`; `packages/edk-http/src/edk/http/handlers/preflight.es`; `packages/edk-http/src/edk/http/package_smoke.es`; `std-requirements/http/verify.sh`. | Covered for scope mismatch, unsupported method, invalid URL/path/port, invalid header name/value, non-positive body limit, negative body length, body-limit overflow, timeout, redirect, and retry policy. Private/reserved hosts remain source-classified for future policy metadata but are not rejected by default, so local test servers can use the same HTTP path. Package-local runtime smoke executes public `request(...)` for unsupported method, invalid URL, request body-limit overflow, and negative body-length rejection and observes the corresponding `HttpError` before transport; the positive pure-surface fixture executes the full preflight helper and returns `0`. Successful loopback network execution requires explicit `--allow-effects --allow-net 127.0.0.1:<port>` and returns `0`; the no-allow-net path fails closed. |
| TCP/TLS/Stream/codec failures map to `HttpError` and are not swallowed. | `packages/edk-http/src/edk/http/transport.es`; `packages/edk-http/src/edk/http/package_smoke.es`; `std-requirements/http/positive/edk_http_error_mapping_contract`. | Covered at source mapping level. Full runtime replay waits on lower substrate orchestration. |
| Std codec `Result` values can be inspected before `unwrap`. | `packages/edk-http/src/edk/http/transport.es`; `std-requirements/http/positive/http_codec_result_match`; `std-requirements/http/positive/std_bytes_len_runtime`; `std-requirements/http/verify.sh`. | Covered: `std.result.is_err`, `std.bytes.len`, and `match decode_response(...) { Ok/Err(MalformedMessage) }` are runtime-callable in fixtures. |
| Response body limit is enforced at the read boundary and overflow maps to a distinct error. | `packages/edk-http/src/edk/http/transport.es`; `std-requirements/http/positive/stream_error_limit_import`; `std-requirements/http/positive/stream_error_limit_variant`; `std-requirements/http/verify.sh`. | Covered in EDK source using direct `import std.stream.{LimitExceeded}`: TLS/TCP `read_until_limit` overflow maps to `response_body_limit`. Both direct import and qualified `StreamError.LimitExceeded` forms are source-visible and runtime-matchable. |
| Request headers are encoded through std HTTP wire types. | `packages/edk-http/src/edk/http/wire/lower_request.es`; `packages/edk-http/src/edk/http/package_smoke.es`; `std-requirements/http/positive/http_wire_request_shape`; `std-requirements/http/positive/edk_http_error_mapping_contract`. | Covered: EDK injects checked `Host` authority, checked `connection: close`, and checked `content-length` for non-empty request bodies, forwards caller headers as `List<HttpHeader>`, rejects caller-supplied managed headers in preflight, and strips caller `Host`/`Connection`/`Content-Length` from direct wire lowering as defense in depth. |
| Request body is encoded through std HTTP wire types. | `packages/edk-http/src/edk/http/wire/lower_request.es`; `packages/edk-http/src/edk/http/body/bytes.es`; `packages/edk-http/src/edk/http/package_smoke.es`; `std-requirements/http/positive/http_wire_request_shape`; `std-requirements/http/positive/std_bytes_len_runtime`. | Covered: EDK stores request body bytes in `RequestBody.raw`, text helpers fill it with `std.codec.text.utf8_encode`, byte helpers accept real `bytes`, and raw byte body length is computed internally with `std.bytes.len(raw)`. |
| Full successful HTTP response body bytes are decoded and returned. | `packages/edk-http/src/edk/http/transport.es`; `packages/edk-http/src/edk/http/wire/decode_response.es`; `packages/edk-http/src/edk/http/package_smoke.es`; `std-requirements/http/positive/http_response_body_text_decode`; `std-requirements/http/positive/http_text_decode_modes`. | Covered in source: package-local raw response helpers decode with `Replace`, the transport checked path decodes with `Strict`, and `InvalidUtf8` maps to `HttpError` via `codec_error`. |
| Public root/API calls can be replayed from external package dependencies with effect facts intact. | `std-requirements/http/positive/external_root_api_effect_facts`; `std-requirements/http/verify.sh`. | Covered: `edk_http` package metadata materializes and the external fixture checks declared `EdkHttp.request` rows. |
| Transport execution should not become a stable external API. | `packages/edk-http/src/edk/http/transport.es`; `tests/blocked/edk-http-default-handler-substrate.txt`. | Blocked on package-private visibility: `api.es` must call `execute_request` across modules, and today that requires `public`. The verifier no longer keeps a fake negative fixture for this gap. |
| Package-local runtime execution of the default handler works through preflight and explicit loopback authorization. | `packages/edk-http/src/edk/http/package_smoke.es`; `std-requirements/http/loopback_server.py`; `std-requirements/http/verify.sh`; `tests/blocked/edk-http-default-handler-substrate.txt`. | Package-local `etas run packages/edk-http` returns `0`, verifier preflight/error flows execute before transport, and the no-allow-net path fails closed with `analysis::MissingHostHandler`. Authorized loopback replay remains optional via `ETAS_HTTP_RUN_LOOPBACK=1`. |
